# specs/

Work specified by the copywriter, waiting to be built. **Written here rather than messaged to a
session, because sessions end and take their inbox with them** — on 2026-09-23 a spec was sent to
a peer session that had already closed, and it was lost.

Anything in this folder is: not started unless it says otherwise, and safe to pick up by any
session that can do the work. Each spec carries its own priority, the exact file and line numbers,
the traps, and what it has to prove before it counts as done.

Delete a spec when it has landed and its Process Alert has passed a review.
